# Syntecxhub Project 2

## Responsive Product/Service Landing Page

This project is a modern responsive landing page developed as part of the **Syntecxhub internship/project**.

The website demonstrates fundamental front-end development skills using HTML5, CSS3, and JavaScript.

## Project Objective

The objective of this project is to create a simple but professional landing page for a product or service.

The page includes:

- A responsive navigation bar
- Hero section
- Product/service introduction
- Features section
- About section
- Call-to-action section
- Responsive mobile navigation
- Smooth scrolling
- Button hover animations
- Navigation link hover effects
- CSS Flexbox
- CSS Grid
- JavaScript interaction

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Responsive Web Design

## How to Run the Project

### Method 1: Open locally

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your default browser.

### Method 2: Use VS Code

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Use the **Live Server** extension if installed.
4. Open the generated local website.
